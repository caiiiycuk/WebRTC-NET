# Tasks

## 1. Независимость истории от URL

- [ ] 1.1 В `coturn-docker/publisher.py` принимать корректный сохранённый binding того же домена без сравнения его URL с текущим `PUBLISH_URL`; сохранить принятую структуру для последующих проверок и записей. Добавить в `test_publisher.py` проверки несовпадающих URL при нулевом и положительном барьере, сохранения файла при загрузке, последовательных обновлений и повторного запуска; выполнить `python3 -m unittest discover -s coturn-docker -p 'test_publisher.py'` из корня репозитория.
- [ ] 1.2 Проверить отправку на текущий URL существующим локальным HTTP fixture при отличающемся сохранённом адресе. Тест должен подтвердить `unknown` на равном положительном watermark после перезапуска, переход к `known` только на более новом здоровом снимке, сохранение watermark до отправки и неизменность исторического binding; прогнать набор `test_publisher.py`.
- [ ] 1.3 Дополнить или переиспользовать отрицательные тесты другого домена, неправильных типов binding и watermark, повреждения/потери/внешнего изменения файла, ошибки durable write, невалидных метрик и не-HTTPS адреса. Проверить, что все они сохраняют прежние запреты на `known`, а тесты publisher проходят полностью.
- [ ] 1.4 Обновить `coturn-docker/README.md`: смена URL не требует редактирования состояния, сохранённый URL является историческим, барьер не сбрасывается, откат на старый publisher может снова отключить capacity. Сверить описание с тестами и исключить рекомендации удалять state или повторно инициализировать существующую историю.
